Getting Started with Git and GitHub

A simple guide to version control and publishing a website.

Experiment Overview

The aim of this experiment is to create a GitHub repository, work with branches, merge changes, and publish a basic website using GitHub Pages.

1

What is Git?

Git is a version control system that keeps track of changes made to files. It helps developers manage different versions of a project.

2

What is GitHub?

GitHub is an online platform where developers can store Git repositories, share code, and work together on projects.

3

Branches and Merging

A branch allows us to make changes separately from the main project. Merging combines those changes back into another branch.

4

GitHub Pages

GitHub Pages is a hosting service that can publish static websites using HTML, CSS, and JavaScript directly from a repository.

Useful Git Commands

These commands are commonly used when working with a repository.

git init — Initialize a repository

git add . — Stage file changes

git commit -m "message" — Save a version

git branch feature — Create a branch

git merge feature — Merge branch changes

git push — Upload commits to a remote repository

Result

A basic informational webpage has been created using HTML, CSS, and Bootstrap. The experiment introduces repository management, branching, merging, and website deployment through GitHub Pages.
